# Azure DevOps Agent / Build Ops Samples (from Azure-Ai)

Public inventory of Azure DevOps helper scripts:

- Agent Pool Health Summary
- List Agents / Pools / Deployment Groups
- Enable/Disable Agent or Build Definition
- Queue Classic Build, Get Build Timeline
- Download Artifacts, Clean Up Old Builds
- Find Agents by Demands/Capabilities
- Update Agent User Capabilities

Source: `Findefra/Azure-Ai`. Production AI stacks live in **Internal-Citadel**.
